
# Employee Management System

## Description
A Java console application that manages employee records using MySQL and JDBC.

## Features
- Add a new employee.
- Search employees by department.
- Update employee salary.
- Delete an employee.
- Handle database errors.

## Technologies Used
- Java
- MySQL
- JDBC
- Eclipse IDE

## Database Structure
Table: Employee

- id: Employee ID
- name: Employee name
- dept: Department
- salary: Employee salary

## Setup
1. Create the employee_db database in MySQL.
2. Create the Employee table.
3. Add the MySQL Connector/J JAR to the Eclipse Build Path.
4. Update the database username and password in DBConnection.java.
5. Run Main.java as a Java Application.

## How to Use
Choose an option from the console menu to add, search, update, or delete employee records.
